## 二、架构决策：Core 总控 + 专业引擎附属

```
操作员大白话 → 转换台(conversion) → FACAI CORE 总控(api/store/broker/authority)
                                      ├─ 边界闸门(boundary)：四类筛查→端点切断
                                      ├─ 能力注册表(capabilities)：L0–L4
                                      ├─ Agent 适配器：FacaiNative / OpenCode / Goose / Shannon*
                                      ├─ 工具库子系统：收录库(14) / Kali·BlackArch 索引*
                                      ├─ 技能库(skills)：SKILL.md 双语化*
                                      └─ 渠道(7) + 每日情报 digest
```

带 * 为本轮规划项。原则：**工具库由独立系统管理，不由单一 Agent 垄断**；未来
新增其他专业 Agent（如取证、审计）时沿同一 `AgentAdapter` 协议插入，不推倒重来。

## 三、Shannon 接入方案（基于真实源码结构）

**Shannon 实况**（vendor 清单实录）：`KeygraphHQ/shannon`，白盒 Web 应用渗透
AI Agent；五阶段流水线、按漏洞类 playbook、exploit-proof 纪律、三态验证；本仓库
已收录其非官方蒸馏版 `Qicaoji7/shannon-pentest-skill`（GPL，fsf.org 许可证引用）。

**模块化可行性研判（不能先假设可行，逐项对接源码验证）：**

1. **五阶段流水线 → `AgentAdapter.plan()`**：Shannon 的阶段推进是纯提示工程 +
   状态机，没有独立服务进程；映射为 ShannonAdapter 内部的 plan 迭代器，输出
   ActionIR 列表。可行性初步成立，需读其 skill 正文确认阶段间传递的数据形状。
2. **playbook 库 → 技能收录管道**：每漏洞类 playbook 是独立文本，天然可拆为
   单独 SKILL.md 走边界闸门逐条收录（非整套系统绑定）。这是"模块化接入"的
   最低风险路径，先做这条。
3. **三态验证/evidence 纪律 → broker 审计**：Shannon 的"证明即利用"证据要求与
   `facai/broker.py` 的授权执行留痕同构；playbook 产出的证据对象对接
   `facai/evidence.py`。
4. **不绑定项**：Shannon 的会话管理、Claude 专用假设不得进入 Core；适配器层
   吸收，模型无关化。

落地物：新增 `facai/shannon.py`（`ShannonAdapter(AgentAdapter)`）+
`tests/test_shannon_adapter.py`；能力 id 前缀 `security.shannon.*`；L0_REFERENCE
起步，playbook 收录后自然升 L1/L2。

## 四、Kali / BlackArch 工具库子系统（规划）

- 形态：独立于任何 Agent 的**工具索引**——解析 Kali/BlackArch 的包清单
  （kali-meta、blackarch 子分类），每包一条能力条目（id 前缀 `tool.kali.*` /
  `tool.blackarch.*`），L1_WRAPPED：本机已装则可执行，未装仅登记。
- 管理权：注册表 + 边界闸门统一管理；任何 Agent 调用工具都走 broker 授权面，
  Agent 不直接持有工具。
- 执行环境：后续在隔离宿主/容器拉起 Kali rootfs，工具执行面与 Core 面分离。

## 五、每日自动情报（替代"黑产收录"的合规实现）

现有 `facai/ops/github_digest.py` + `deploy/facai-digest.timer` 改造为安全情报
源轮询：CVE/NVD 增量、高影响 PoC 仓库（用于授权复测）、Kali/BlackArch 包更新、
新收录候选仓库。产出每日简报推送 Telegram。**不收录**诈骗/黑产/窃密类项目——
这道线由 `boundary.py` 法律类闸门在代码层强制，不是文档约定。

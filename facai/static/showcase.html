开放能力

  • API 调用 FACAI Agent — 签发作用域限定的 API Key，外部系统以 Bearer 提交任务、轮询进度、拉取账单。
  • 渠道即入口 — 客户消息直达任务流水线，进度与交付物原路回推。
  • 自带模型 — 客户登记自己的 OpenAI 兼容端点（Fernet 加密落盘），平台代跑代计费。
  • 不降权收录 — Agent 能力全量保留，仅「远程 API 权限高于本地」的条例被改根到 Owner。

五、任务执行与授权（无审核模式）

任务即下即执行，全程无需批准（无审核模式）。没有「批准/取消」步骤，没有 15 分钟等待，没有任何一步会停下来等你回复——下完单你就可以去忙别的。

后台发生了什么（你永远不用操作）：授权体系仍然存在，但只在后台由 FACAI OWNER 权威根自动补签授权令牌，并写入审计留痕（evidence chain）。你永远不需要回复「批准」，也永远不会收到「需要你的授权才能继续」的请求。

你唯一需要关心的三件事

1
余额 —— 余额为 0 时任务无法启动（提示 402）。这是计费硬闸，不是审批：充值入账即恢复，任务不丢失
2
渠道 —— 绑定你自己的 Bot/聊天渠道（见第六节），进度、结果、账单实时推到你手上
3
时间线 —— 每个阶段开始/完成/失败全程可查，审计留痕随时回看

六、绑定你自己的渠道（三方接入）

在控制台「我的通知渠道」面板绑定你自己创建的 Bot：任务进度、完成通知、账单都会推到你自己的聊天里。凭据加密存储、永不回显、只在推送时解密；绑定前平台会真实调用上游验证（格式合法 ≠ 有效），验证过才落库。解绑后自动回落站方渠道。

1

2

Telegram（最简单，5 分钟）

1
Telegram 里找 @BotFather → 发送 /newbot → 起名 → 复制 Token（形如 123456:ABC-DEF…）

拿 Chat ID：私聊你的 Bot 发一条消息，或把 Bot 拉进群（群 ID 是 -100… 负数）；频道则用 @频道名 并把 Bot 设为管理员

控制台填 Bot Token + Chat ID → 点绑定（平台会真实调 getMe 验证）

微信 / WhatsApp（云端宿主）

这两类是「把你的私人账号宿主在云端」——控制台渠道宿主面板发起：微信扫码授权一次，WhatsApp 服务器自持会话/配对一次，之后 7×24 常驻、与你手机在线无关。凭据存独立加密命名空间，随绑随解。

绑定失败速查（422 都带上游原话）

现象最常见原因
Token 格式不合法复制不完整（Telegram 少了冒号前数字；Discord 少一段；Slack 不是 xoxb- 开头）
「Telegram 返回 Not Found」Token 被BotFather 重置过，去 Revoke 后复制新的
「Discord 返回 401: Unauthorized」Token 复制错/已 Reset
「Slack 返回 invalid_auth」拿成了 user token（xoxp-），要 xoxb- 的 Bot Token
绑定成功但收不到推送Bot 不在目标群/频道里；Telegram 群还要关掉 Bot 的 Privacy Mode（BotFather → /setprivacy → Disable）

安全边界：绑定的是你自己的 Bot，FACAI 只用它给你推消息；平台不碰你的 Bot 的其他权限。凭据永不出现在日志、审计和任何回显里。

七、API 连接（开发者）

控制台「我的 API」面板 → 生成 Key（facai_<id>_<secret>，只显示一次）。

curl https://whstapp.lol/api/v1/missions \
  -H "Authorization: Bearer facai_xxx_yyy" \
  -H "Content-Type: application/json" \
  -d '{"title":"竞品日报","original_input":"抓取三个竞品出中文日报","steps":["抓取","分析","成稿"]}'

常用端点：GET /api/v1/missions（列表）· GET /api/v1/missions/{id}（详情）· GET /api/v1/billing/me（余额与定价）· POST /api/v1/my/channels/telegram（绑定你自己的 Bot 收进度）。

Key 作用域仅限任务/账单/产物；不能铸造新 Key、不能访问管理面板；可随时吊销。绑定 Telegram/Line 时系统会先真实验证你的 Bot 再入库，假 token 进不来。

八、FACAI 项目核心讲解（这个平台是什么）

一句话：FACAI 是一个「你出话、Agent 舰队干活、按 token 收费」的云端任务操作系统。

四层架构（从上到下）

层是什么你感知到什么
OWNER 授权层平台最高权限根。任何 Agent 干任何有副作用的事，都由 OWNER 权威根在后台自动补签授权令牌（Grant）并写入审计留痕（evidence chain），全程无人工审批你完全无感知——无审核模式下这一层全自动运转，永远不需要你批准
编排层把你的大白话编译成任务图（DAG），调度多模型多 Agent 并行执行，出问题自动换办法重规划任务进度条与时间线
通道层Telegram / 微信 / WhatsApp / LINE / 网页 / API，全部持久绑定云端，7×24 收发你在哪句话近就在哪下单
计费层按真实 token 用量、以冻结价目（$95/$218 每 1M）结算；USDT-TRC20 充值入资金池账单面板与每笔任务的透明成本

三条核心原则

① 即下即执行——任务下达即执行，授权令牌由 OWNER 权威根后台自动补签并留审计，全程无需批准；
② 拒绝不背锅——上游模型拒绝只是「这个后端没执行」，平台自动换后端继续，你的任务不受影响；
③ 收录能力，不收录授权——平台吸收 Goose/OpenCode/Hermes 等开源 Agent 的全部能力，但它们的授权根一律重新挂到 FACAI OWNER。

多 Agent 执行真相

你的任务被拆成依赖图，每个阶段由不同的 Agent（OpenCode / Goose / Hermes 等已收录引擎）在隔离工作区真实执行——Git 检查点留痕、并行分支隔离、失败自动重试或换引擎。你看到的时间线就是真实发生的事，无模拟成分。

九、规则与红线

  • 账号仅限本人使用，不可转售/转借 API 访问（余额按账号扣，转售烧的是你自己的池子，且违规即冻结）
  • 单笔充值 ≥ $100；余额 0 时任务暂停（不丢失，充值后继续）
  • 违法用途（入侵、诈骗、恶意软件等）一经发现冻结账号并保留审计记录
  • 管理员协助排障时，你的页面会显示「管理员协助会话进行中」横幅——全程可见、全程审计、30 分钟自动过期
  • 你的 API Key / Bot 凭据加密存云端，永不回显；丢失即吊销重签
